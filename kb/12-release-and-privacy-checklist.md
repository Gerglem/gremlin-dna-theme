# 12 – Release and Privacy Checklist

This repository is public. **Nothing that identifies the maintainer goes in it:** no names, emails, locations, employer, device serial numbers, measured personal values, or personal history. Public docs refer to "the maintainer" generically.

## Commit identity
All commits go through Claude Code on the maintainer's machine, using:
`Gerglem <91816923+Gerglem@users.noreply.github.com>`
Never commit with a real name or personal email. If history ever exposes something, replace history with a single clean commit (or delete and recreate the repo; the maintainer does deletions).

## Before every commit
1. Scan all text files **and decoded base64 inside theme, profile, and config files** for personal names, emails, and serial numbers.
2. Check images for metadata: no EXIF or GPS (resaving through PIL strips it). Files delivered by Claude carry a C2PA "Claude provided this file" tag, which contains no personal data.
3. Verify every relative link resolves, including links from live Reddit posts (`reddit/` pointer files).
4. Keep the private build kit and private notes out of the repo.

## Sanitizing an EScribe `.ecig` export
Exports contain the maintainer's real device state. Always fix these before publishing (`DEScribe.xml` inside the zip; text values are base64 UTF-8):
- `EvolvWDColdOhms` → 0 and `EvolvWDOhmLock` → 0 for every slot. **Exports have contained the maintainer's measured cup resistances with the lock on every time.**
- `EvolvWDColdOhmsTemperature` → 70 where present.
- `EvolvATFriendlyName` (profile names), `EvolvPSPower`, `EvolvPSTemperature`, `EvolvWMEnable`, `EvolvWMTime` → the published profile values (`03`).
- `EvolvXHiddenProfile` → 1 for unused slots 5–8.
- `EvolvBatterySoftVoltage` → 3.
- `EvolvThemeTitle` correct, `EvolvThemeAuthor` empty.
- High Contrast only: `EvolvXAutoLock` → 0.
- Leave `EvolvXPassword` (FFFFF) and `EvolvPowerLockPassword` (SSS); they are Evolv defaults.
- Keep the zip entry name `DEScribe.xml`, the UTF-8 BOM, and CRLF line endings. Back up the source first, then print a slot table to verify.

## Naming and versions
- Themes: `Gremlin-Color-Themes.ecigtheme` (no version in the name — download links have to survive a release). High Contrast is on its own track and still versions its filename: `Gremlin-High-Contrast-Large-Text-vX.Y.ecigtheme`. Test builds add `-vX.Y-betaN`.
- Full setups: `Gremlin-Color-Themes-Full-Setup.ecig`, exported by the maintainer from EScribe (themes are stored compiled inside `.ecig`, so they can't be generated by script).
- **When a version bumps the filenames do not change.** Bump the version where it is actually stored — `<Comments>` in the `.ecigtheme` and `EvolvThemeComments` (base64) in the `.ecig`, which both begin "Gremlin - Color Themes vX.Y." — then add a `RELEASE-NOTES.md` entry and update the version in `README.md`, `AI-GUIDE.md` and the "Current state" table in `00`.
- `.gitattributes` keeps `*.csv` as CRLF (`-text`); don't let tooling normalize them.
